# Business English lesson videos

Drop each finished clip here with the exact file name below and the app picks it up. Until a file exists, the lesson shows a "Video coming soon" card that reads the scene script aloud instead.

Names follow the Video Category Map: `umbrella_industry_topic_level.mp4`. Industry versions replace `core` with the industry id (for example `pitching_nonprofit_asking-for-funding_confident.mp4`) and need a matching lesson entry in `business-lessons.js`.
